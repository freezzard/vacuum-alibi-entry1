One line, at most 200 characters: the funniest excuse a robot vacuum can give for missing a spot. `main.ts` (Node 22) composes a handful of deadpan first-person excuses, scores each against the judge's published brief — deadpan machine voice, a joke that lands, surprise with a specific detail, punch at the end — picks the strongest, validates it against the gate, and writes it to `/output/entry.txt`. Fully deterministic: no network, no clock, no randomness.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
